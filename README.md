# 🌍 旅游端水大师 — Travel Balancer

> 一场公平的旅行，从了解彼此开始。
>
> **端水大师** 是一款 AI 驱动的多人旅行规划工具，解决「众口难调」这个经典难题。
> 每位成员独立提交偏好（预算、节奏、作息、心愿），多个 AI Agent 协作分析冲突、设计双方案、并以高情商的方式解释协调理由。

---

## 📌 产品背景

组织过多人旅行的人都有这种体验：

- 有人是「特种兵」，有人只想「躺平」
- 有人无辣不欢，有人不吃香菜
- 有人预算宽裕，有人精打细算
- 更麻烦的是：有些需求不好意思当面说

传统的解决方案（微信群投票、Excel 表格）本质上是**零和博弈**——有人满意就有人妥协。端水大师试图用 AI 的协调能力将「妥协」转化为「设计」，让每个人的需求都被看见。

## 🎯 核心设计理念

| 原则 | 说明 |
|---|---|
| **一人一链 · 信息隔离** | 每位成员通过独立链接填写偏好，彼此不可见，避免「从众效应」和社交压力 |
| **盲选机制** | 心愿单可标记为「保密」，AI 会在最终方案中匿名体现，保护隐私 |
| **AI 协调而非投票** | 不靠多数决，而是分析深层冲突，输出兼顾多方的方案 |
| **双方案并行** | 同时输出「集体妥协」和「分头行动」两套方案，让用户选择而非被迫接受 |
| **有温度的沟通** | 每个安排都附有解释——「为什么这么排」，让成员感受到被照顾 |

## 🧠 AI Agent 架构

系统由 3 个 CrewAI Agent 串联工作：

```
           ┌──────────────┐
           │  冲突分析师   │  ← 分析成员偏好之间的隐性对立
           │  (Negotiator) │     输出：冲突/共识分析报告
           └──────┬───────┘
                  ▼
    ┌─────────────────────────┐
    │     双轨规划师          │  ← 基于冲突报告，同时设计两套方案
    │     (Planner)           │     方案A：集体妥协 / 方案B：分头行动
    └──────────┬──────────────┘
               ▼
    ┌─────────────────────────┐
    │     端水大师            │  ← 用同理心润色方案，向每位成员
    │     (Presenter)         │     解释安排理由
    └─────────────────────────┘
```

另有 **个人管家 (Concierge) Agent**，单人模式时跳过冲突分析环节，直接定制专属攻略。

## 👤 用户流程

```
创建旅行 → 生成成员邀请链接 → 成员独立填写「旅行DNA」 → 
管理员一键触发计算 → AI 输出双方案 → 团队投票/选择
```

### 成员体验：旅行 DNA 测验（4 关）

1. **🏃 体力挑战** — 滑杆选择 1-10 的旅行节奏
2. **💰 消费画像** — 省钱党 / 适中派 / 宽裕派
3. **🌙 作息密码** — 早睡早起 / 正常作息 / 夜猫子
4. **🎁 心愿盲盒** — 自由写下必做事项和避雷指南（可保密）

## 🗺️ 核心功能

- **多 Agent 协作** — 冲突分析 → 双轨规划 → 情商润色，自动串联
- **AB 双方案输出** — 帕累托妥协路线（集体行动） + GACO 动态子群路线（分头+汇合）
- **地图可视化** — 接入高德地图，按日分色展示路线，点击标记查看交通耗时
- **天气预报集成** — 自动获取目的地天气，影响行程推荐
- **数据隔离** — 每位成员数据独立存储，JSON 文件持久化
- **隐私保护** — 心愿单可匿名处理，不公开归属

| 前端 | Streamlit |

| 搜索 | DuckDuckGo（实时景点/餐厅查询） |

```

    └── test_core.py
```
